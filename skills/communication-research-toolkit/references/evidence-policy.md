# Evidence Policy

Use this hierarchy when collecting or judging research evidence.

Level 1:
- Official paper
- Supplementary material
- Official repository
- Official dataset or experiment artifact

Level 2:
- Project page
- Author homepage
- Venue page
- Official patent or technical report

Level 3:
- Trusted third-party reproduction
- Well-maintained benchmark implementation
- Survey paper with clear citations

Level 4:
- Blog
- Forum
- Social media
- Unverified summary

Prefer higher-level evidence. If a claim depends only on Level 3 or Level 4 evidence, label it as weakly supported.
