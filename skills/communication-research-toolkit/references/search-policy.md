# Search Policy

Priority:

1. Official paper or arXiv version
2. Supplementary material
3. Official repository
4. Project page
5. Author homepage
6. Venue page
7. Trusted reproduction
8. Survey or tutorial that cites primary sources

Stop conditions:

- Do not repeat the same search more than 3 times.
- Do not revisit the same source more than 3 times unless the user asks for close reading.
- Stop expanding search when new results no longer change the answer.

When metadata, code, or venue cannot be found, state `[NOT FOUND]` and continue.
