# Failure Handling

Use explicit markers instead of guessing.

Missing information:

`[NOT FOUND]`

Insufficient evidence:

`[INSUFFICIENT EVIDENCE]`

Repeated search or no new information:

`[PROCESS TERMINATED]`

If a paper, codebase, or experiment is partially available, continue with the available evidence and list what remains unknown.

If a proposed research idea fails a core feasibility gate, say so directly and suggest either a narrowed version or a reason to discard it.
