# GPS路径响应秩退化的循环条件推导草稿

## 适用范围

本推导针对整数时延、整数多普勒、接收端已知所选预啁啾模式并采用匹配DAFT解调的AFDM系统。目标是分析候选预啁啾结构是否会使某些有限星座错误事件失去路径分集，而不是分析完整有效信道矩阵的秩。

## 两路径错误事件模型

设两条单位增益路径在候选模式q下的有效矩阵为H1(q)和H2(q)。对于非零符号差分delta_x，定义

Psi(q, delta_x) = [H1(q) delta_x, H2(q) delta_x].

在两条独立Rayleigh路径增益下，该错误事件的分集阶数由rank(Psi)决定。发生一阶退化当且仅当存在复数lambda，使

H2(q) delta_x = lambda H1(q) delta_x.

整数时延和多普勒下，每条单位路径矩阵为酉单项矩阵。因此定义相对路径算子

R(q) = H1(q)^H H2(q),

则退化条件等价于

R(q) delta_x = lambda delta_x.

因此问题可转化为：R(q)是否存在属于有限星座差分集合的特征向量。

## 置换循环

单项矩阵R对标准基的作用写为

R e_m = a_m e_{pi(m)},

其中|a_m|=1，pi为置换。在当前代码的符号约定和第一路径(0,0)条件下，第二路径(l, alpha)对应的固定置换位移为

eta = -(alpha + 2 N c1 l) mod N.

更一般的两路径相对位移应由时延差和多普勒差代替l和alpha，CPP相位只进入a_m而不改变置换位置。

固定循环位移的每个置换循环长度为

L = N / gcd(N, eta).

在当前代码的DAFT符号约定下，单条整数路径对标准基向量的作用可以显式写为

H(l, alpha) e_q = a_q e_pi(q),

其中

pi(q) = (q + eta) mod N,

eta = -(alpha + 2 N c1 l) mod N,

b_q = exp(j 2 pi/N * (N c1 l^2 - ql)),

d_q = exp(-j 2 pi c2_q q^2),

a_q = b_q d_pi(q) conjugate(d_q).

该公式已经针对baseline、GPS和局部扰动，以及四组时延多普勒支撑与现有完整矩阵实现逐元素比较，Frobenius误差均低于1e-10。

若循环为C={m, pi(m), ..., pi^(L-1)(m)}，特征向量满足递推关系

delta_x[pi(m)] = (a_m / lambda) delta_x[m],

以及闭合条件

lambda^L = product_{m in C} a_m.

单项矩阵总存在复数特征向量，但只有当某个特征向量经整体缩放后，其循环内所有元素均属于非零星座差分集合时，才构成实际通信系统中的分集退化错误事件。

## 有限星座旋转循环的精确条件

对具有Q重旋转对称性的等幅差分壳层，设循环C上的系数相位为beta_r=arg(a_r)。存在有限星座兼容特征向量，当且仅当存在一个特征值相位phi，使

beta_r - phi = 2 pi z_r / Q mod 2 pi, for every r,

并且满足完整循环闭合条件

L phi - sum_r beta_r = 0 mod 2 pi.

第一条保证每一步递推比例属于Q次单位根，第二条保证绕循环一周后回到原始差分值。只检查相邻相位属于单位根会对QPSK和16QAM多预测危险支撑，因此完整闭合条件不可省略。

对于BPSK取Q=2；对于QPSK和方形16QAM的等幅旋转壳层取Q=4。在N=64、56种路径支撑上，该标量相位判据与直接数值特征向量搜索实现168/168完全一致。

对有理GPS，可先用

gcd(N, eta) > 1,

Q l eta = 0 mod N

进行快速筛选。该同余条件在当前BPSK网格上即为精确结果；对QPSK和16QAM还需要应用上面的完整循环闭合条件排除伪阳性。

## GPS为何更容易满足有限星座兼容性

GPS在W=2时采用近似

c2_m = plus_or_minus 1/(4m^2).

因此预啁啾相位exp(j 2 pi c2_m m^2)基本退化为少量固定相位。重复相位使相对路径算子中的a_m也呈现高度规则的有限相位结构，从而可能使循环特征向量恰好落入BPSK或QPSK差分集合。

基准无理数c2和局部扰动c2_base+delta通常破坏这种精确相位闭合。需要注意，“通常破坏”不是全局证明；正式权利要求仍需给出可计算的安全判据，而不能只规定delta很小。

GPS的无理修正也不能仅凭“每一项c2_m为无理数”排除循环。对于全1或全2分组模式，所有非零位置的诱导相位d_q仍为同一个常数。在不包含q=0的置换循环上，d_pi(q)conjugate(d_q)=1，无理相位因子完全抵消，路径系数退化为b_q。因此全同模式仍可能存在严格有限星座兼容循环。对于混合分组模式，无理修正通常只把严格退化变成近退化，其安全裕量取决于偏离pi/2的相位量，而不是“无理”这一标签。

## 已验证配置

### N等于8

- V=4，alpha_max=2；
- 第二路径为(l,alpha)=(2,2)；
- eta=4，gcd(N,eta)=4，循环长度L=2；
- GPS存在6个BPSK兼容特征向量，最小错误事件权重为2；
- baseline和局部扰动未发现兼容特征向量。

### N等于16

- V=4，alpha_max=2；
- 第二路径为(2,2)；
- eta=4，循环长度L=4；
- GPS最小兼容错误事件权重为4；
- 这解释了此前权重不超过2的搜索没有发现秩损失。

### N等于64

- V=4，alpha_max=3，c1=7/(2N)；
- 第二路径为(2,2)；
- eta=48，gcd(N,eta)=16，循环长度L=4；
- 一个GPS兼容差分的零基索引为{1,17,33,49}，四个非零值可同取-2j；
- 对该差分，GPS的rank(Psi)=1且路径响应相关系数为1；
- baseline和局部扰动的rank(Psi)=2，最小奇异值分别约为0.9089和0.9059。

## N等于64的路径支撑扫描

在delay=1..8、Doppler=-3..3的56种第二路径支撑中，模式[2,2,1,1]得到：

| 第二路径(delay,Doppler) | eta | 循环长度 | GPS最小兼容权重 |
|---|---:|---:|---:|
| (2,2) | 48 | 4 | 4 |
| (5,-3) | 32 | 2 | 2 |
| (8,0) | 8 | 8 | 8 |

GPS在3/56种支撑中存在严格BPSK兼容事件；baseline和局部扰动在当前扫描中均为0/56。

## 与固定信道MMSE平台的区别

rank(Psi)不依赖具体路径增益，而固定信道MMSE平台依赖路径幅度和相位。即使三种方案的完整H_eff具有相同秩和奇异值，pinv(H_eff)H_eff在星座坐标系中的方向仍可不同。GPS可能使投影后的部分有限星座点落到判决边界，从而在零噪声条件下产生错误。

因此后续应分别报告：

1. 基于rank(Psi)的随机路径分集结论；
2. 基于判决裕量和BER邻域的固定信道线性检测鲁棒性结论。
